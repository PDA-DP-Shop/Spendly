Diagram 2

Activity Diagram (Checkout & Billing)

Flow diagram representing the cashier checkout matching, claim checking, and invoice transmission.

graph TD
    Start([Start: Checkout Initiated]) --> Scan[Cashier Scans Item Barcode]
    Scan --> Query[Query Radar via P2P PRODUCT_REQUEST]
    Query --> CheckRadar{Item found in stock?}
    CheckRadar -->|No| Warn[Alert Cashier: Product Not Registered]
    CheckRadar -->|Yes| Fetch[Fetch product details & catalog price]
    
    Warn --> End([End Checkout])
    
    Fetch --> Calc[Calculate base price & apply GST / VAT]
    Calc --> HasCoupon{Shopper has Radar offer coupon?}
    
    HasCoupon -->|Yes| Validate[Send claim code via P2P OFFER_VALIDATE_REQUEST]
    Validate --> CheckValid{Coupon Code valid & unused?}
    CheckValid -->|Yes| ApplyDiscount[Apply offer discount to invoice]
    CheckValid -->|No| RejectCoupon[Show error: Coupon Rejected]
    
    ApplyDiscount --> Compile[Compile final invoice summary]
    RejectCoupon --> Compile
    HasCoupon -->|No| Compile
    
    Compile --> ReduceStock[Send P2P STOCK_REDUCE packet to Radar DB]
    ReduceStock --> SaveSale[Save sales transaction locally in Shop IndexedDB]
    
    SaveSale --> SelectBeam{Select beam transport}
    SelectBeam -->|WebRTC Direct| BeamRTC[Beam invoice JSON over paired WebRTC]
    SelectBeam -->|Web NFC Tap| BeamNFC[Beam invoice JSON over NFC channel]
    SelectBeam -->|Camera Scan| BeamQR[Generate Dynamic QR on screen for camera scan]
    
    BeamRTC --> SaveUser[User imports invoice into Wallet IndexedDB]
    BeamNFC --> SaveUser
    BeamQR --> SaveUser
    
    SaveUser --> OptIn{Is User opted-in to analytics?}
    OptIn -->|Yes| PushTrends[POST anonymous category & amount to Radar shard]
    OptIn -->|No| Done([Complete Purchase])
    PushTrends --> Done

Sequence Diagram

Chronological workflow of checkout, claim check, and data streaming.

sequenceDiagram
    autonumber
    actor Shopper as Spendly User
    actor Retailer as Spendly Shop
    actor Hub as Spendly Radar
    participant Ntfy as WebSocket Bridge

    Note over Shopper, Hub: All devices paired via WebRTC/ntfy.sh
    
    Shopper->>Hub: Query local offers (OFFERS_QUERY)
    Hub-->>Shopper: Return active discounts (OFFERS_RESPONSE)
    Shopper->>Shopper: Tap "Claim Coupon" -> save claim code
    
    Retailer->>Retailer: Scan product barcode "890103"
    Retailer->>Hub: Query product details (PRODUCT_REQUEST)
    Hub-->>Retailer: Return stock info (PRODUCT_RESPONSE)
    
    Retailer->>Retailer: Apply product to invoice
    Shopper->>Retailer: Show claim QR code
    Retailer->>Hub: Check validity (OFFER_VALIDATE_REQUEST)
    Hub->>Hub: Check claim ledger DB
    Hub-->>Retailer: Code approved (OFFER_VALIDATE_RESPONSE)
    
    Retailer->>Retailer: Deduct discount and compile final bill
    Retailer->>Hub: Subtract inventory item count (STOCK_REDUCE)
    Hub->>Hub: Update stock count in IndexedDB
    
    Retailer->>Shopper: Beam invoice payload (Web NFC Tap / WebRTC)
    Shopper->>Shopper: Save invoice to expenses DB
    
    opt Privacy Analytics Opt-in
        Shopper->>Ntfy: Send category & amount (Mumbai/Powai topic)
        Ntfy-->>Hub: Relay packet anonymously to Radar
        Hub->>Hub: Log to areaIntelligence DB for charts
    end
