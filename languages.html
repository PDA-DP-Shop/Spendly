Tech Stack Overview

💻 Language & Technology Directory

An exhaustive analysis of all languages, frontend libraries, serverless backend engines, databases, and APIs running in the Spendly ecosystem.

🔤 Core Languages & Formats

JS (ES6+)

Runs all ecosystem logic, including direct WebRTC PeerJS channels, Dexie.js database transactions, and Cloudflare Worker endpoints.

HTML5 / CSS3

Provides semantic structures and responsive styling using custom Tailwind configurations.

JSON

Standard format for billing transfers, inventory catalogs, and IndexedDB encryption exports.

RegExp

Executes on-device clipboard regex parsing to log debited amounts, merchants, and categories from bank SMS alerts.

🖥️ Frontend Libraries & Frameworks

React (v18 & v19)

Spendly (personal wallet) and Shop run on React 19, and Spendly Radar operates on React 18, managed dynamically under Vite compiler pipelines.

Tailwind CSS (v3 & v4)

Shop and Spendly personal wallet apps leverage Tailwind v4 engine configurations, while Radar utilizes Tailwind v3 layouts.

Zustand (v5)

Stores app memory globally on client runtimes using lightweight, concurrent store hooks.

Recharts (v2 & v3)

Renders localized Mumbai area spending intelligence metrics via interactive SVG charts on Radar dashboards.

Tesseract.js

Provides offline optical character recognition (OCR) inside browsers to extract text descriptions from receipt photos.

jspdf & html2canvas

Compiles HTML invoice states into PDF files directly on client screens for downloading.

jsbarcode & qrcode

Generates product barcode structures (bwip-js/jsbarcode) and dynamic billing codes.

💾 Databases & Local Storage

IndexedDB

The browser's native client-side database. It bypasses localStorage storage limits (up to 5MB) to store gigabytes of transactions on disk.

Dexie.js

A database wrapper that enables fast, asynchronous transaction queries on the main execution thread.

Workers KV

Cloudflare's distributed key-value store. It stores temporary 6-digit WebRTC pairing pins and backup catalog stock files.

🔌 Backend, Relays & Connection APIs

Cloudflare Workers

Serverless V8 execution environments. They host pairing matchmaker APIs without monthly database subscription fees.

WebRTC (PeerJS)

Enables direct, browser-to-browser P2P data streams between the Shop register, User wallet, and Radar hub.

Web USB & CSS Print APIs

Enables connecting physical thermal receipt printers and printing structured paper receipt slips using CSS @media print layout sheets.

WhatsApp Redirect API

Builds fast template strings to share formatted transaction details over chat using WhatsApp wa.me links.

WebAuthn API

Locks local client databases behind the device's hardware Secure Enclave using Passkeys biometrics.
